# YouTube Subtitle Overlay Activation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make YouTube auto-activated subtitles work when caption tracks are embedded in the player response and direct timedtext fetches require YouTube's runtime token.

**Architecture:** Add a small MAIN-world YouTube player helper that discovers embedded caption metadata and can request/restore native captions through the stable caption button. Wire it through the existing postMessage bridge, then make the isolated coordinator invoke that fallback once after a direct YouTube timedtext fetch fails or yields no cues. The existing interception, translation, and overlay renderer remain the only display pipeline.

**Tech Stack:** TypeScript, WXT MAIN/ISOLATED content scripts, `window.postMessage`, Vitest, jsdom, ESLint, TypeScript compiler.

## Global Constraints

- Do not reimplement YouTube PoToken generation.
- Do not change subtitle translation, cue parsing, ASR resegmentation, or renderer behavior outside YouTube activation.
- Use `.ytp-subtitles-button` and `aria-pressed` for native-caption state.
- The fallback must be idempotent per YouTube timedtext URL and reset on SPA navigation.
- Restore native captions only when they were enabled by the extension fallback.
- Production code must be preceded by a failing test.
- Do not commit or push unless the user explicitly authorizes it.

- [ ] **Step 5: Implement `inject/youtubePlayer.ts`**

Use these exact contracts and behaviors:

```ts
import type { AvailableSubtitleTrack, SubtitleTracksDiscoveredPayload } from '@/types/subtitle';
import type { MessageBridgeSender } from '@/inject/messageBridge';
import { YouTubeHandler } from '@/inject/subtitleHandlers/youtube';

const YOUTUBE_CAPTION_BUTTON_SELECTOR = '.ytp-subtitles-button';
const DISCOVERY_RETRY_MS = 250;
const DISCOVERY_RETRY_LIMIT = 40;
const CAPTION_BUTTON_RETRY_MS = 200;
const CAPTION_BUTTON_RETRY_LIMIT = 10;

type YoutubeWindow = Window & {
  ytInitialPlayerResponse?: unknown;
  ytplayer?: {
    config?: {
      args?: {
        raw_player_response?: unknown;
      };
    };
  };
};

const youtubeState = {
  captionsEnabledByExtension: false,
  captionButtonRetry: null as ReturnType<typeof setTimeout> | null,
};

function parseResponseCandidate(candidate: unknown): unknown | null {
  if (candidate && typeof candidate === 'object') return candidate;
  if (typeof candidate !== 'string') return null;
  try {
    const parsed: unknown = JSON.parse(candidate);
    return parsed && typeof parsed === 'object' ? parsed : null;
  } catch {
    return null;
  }
}

function readEmbeddedPlayerResponse(win: Window = window): unknown | null {
  const youtubeWindow = win as YoutubeWindow;
  return (
    parseResponseCandidate(youtubeWindow.ytInitialPlayerResponse) ??
    parseResponseCandidate(youtubeWindow.ytplayer?.config?.args?.raw_player_response)
  );
}

function emitEmbeddedTracks(
  handler: YouTubeHandler,
  bridge: MessageBridgeSender,
): string | null {
  const response = readEmbeddedPlayerResponse();
  if (!response) return null;
  const tracks = handler.extractAvailableTracks(JSON.stringify(response));
  if (tracks.length === 0) return null;
  const videoId = tracks.find((track) => track.videoId)?.videoId;
  bridge.send('SUBTITLE_TRACKS_DISCOVERED', {
    tracks,
    platform: 'youtube',
    ...(videoId ? { videoId } : {}),
  } satisfies SubtitleTracksDiscoveredPayload);
  return [
    videoId ?? '',
    ...tracks.map((track: AvailableSubtitleTrack) =>
      `${track.language}:${track.isAutoGenerated ? 'asr' : 'manual'}:${track.url ?? ''}`),
  ].join('|');
}
```

`startYoutubeMetadataDiscovery` must:

1. Emit immediately.
2. Retry every 250 ms up to 40 times if the response is not yet present.
3. Clear and restart the retry window on `yt-navigate-finish`.
4. Suppress duplicate emissions using the returned video/track key.
5. Remove the navigation listener and pending timer in its cleanup function.

The native-caption helper must use this behavior:

```ts
function findCaptionButton(): HTMLButtonElement | null {
  return document.querySelector<HTMLButtonElement>(YOUTUBE_CAPTION_BUTTON_SELECTOR);
}

export function requestYoutubeNativeCaptions(): void {
  if (youtubeState.captionsEnabledByExtension || youtubeState.captionButtonRetry) return;

  let attempts = 0;
  const attempt = () => {
    const button = findCaptionButton();
    if (button) {
      youtubeState.captionButtonRetry = null;
      if (button.getAttribute('aria-pressed') !== 'true') {
        button.click();
        youtubeState.captionsEnabledByExtension = true;
      }
      return;
    }
    attempts++;
    if (attempts >= CAPTION_BUTTON_RETRY_LIMIT) {
      youtubeState.captionButtonRetry = null;
      return;
    }
    youtubeState.captionButtonRetry = setTimeout(attempt, CAPTION_BUTTON_RETRY_MS);
  };

  attempt();
}

export function restoreYoutubeNativeCaptions(): void {
  if (youtubeState.captionButtonRetry) {
    clearTimeout(youtubeState.captionButtonRetry);
    youtubeState.captionButtonRetry = null;
  }
  if (!youtubeState.captionsEnabledByExtension) return;

  const button = findCaptionButton();
  if (button?.getAttribute('aria-pressed') === 'true') {
    button.click();
  }
  youtubeState.captionsEnabledByExtension = false;
}
```

The implementation may add the bounded retry loop and cleanup helpers around
these contracts, but it must not click the button when `aria-pressed="true"`.

function requestYoutubeCaptionFallback(track: AvailableSubtitleTrack): void {
