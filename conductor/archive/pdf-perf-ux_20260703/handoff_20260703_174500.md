## Section 3 Implementation Decisions

### 1. Font-metrics overlay sizing (Phase 5 Task 1)
- New `lib/fontMetrics.ts`: Canvas `measureText`-based per-word width measurement
  (`measureWord`/`measureBoxHeight`/`wrapTextIntoLines`) with per-`(fontFamily, fontSize, word)` cache.
- Replaced the crude `chars × avgCharWidth` heuristic in `PdfTranslationPane.estimateBoxHeight` →
  translated boxes now size correctly on FIRST paint (no collision flash before the reflow effect runs).
- Defensive: `getMeasureCtx` returns null when canvas/`measureText` unavailable → heuristic fallback.

### 2. Download queue progress + cancel (Phase 5 Task 3)
- `usePdfDownload` now reports total page count in the progress message.
- Skips `translateAllPages` entirely when nothing needs translation.
- Generation-stage cancel no longer aborts mid-page pdf-lib writes (signal withheld from
  `generateTranslatedPdf`); in-flight generation completes gracefully, cancelled job never triggers download.

### 3. Bilingual view mode (Phase 5 Task 2)
- Third PDF view mode `'bilingual'` (single column, original-above-translation per paragraph).
- New `BilingualView` component; persisted via existing `anyllm-pdf-view-mode` key.
- ViewerLayout helpers `isSingleColumn`/`paneLabel` centralize the mode→layout decision.

### 4. Progress persistence (Phase 6 Task 1)

  save/load/clear with defensive shape validation.
