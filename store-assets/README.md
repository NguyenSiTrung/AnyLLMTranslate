## What each image shows

1. **Bilingual page** — a documentation-style article with each paragraph's
   Vietnamese translation rendered directly beneath the original.
2. **Popup** — the action popup open on that page: source/target language
   selectors, the translate action and its `Alt+A` shortcut, per-page controls,
   and the provider chips.
3. **Providers** — the provider pool with the configured endpoint healthy,
   alongside two disabled presets. The API-key field is empty; nothing to redact.
4. **Subtitles** — the bilingual caption overlay over a playing video, original
   cue above the translation.
5. **Disclosure** — step 2 of the setup wizard, listing every data type the
   extension handles and where each one goes, with consent accepted.

## How they were captured

All five were captured from the built extension the store zip ships
(`pnpm build` → `.output/chrome-mv3`, version 1.0.0), loaded unpacked in
Google Chrome 154 on Linux and driven over CDP. The tab viewport was pinned to
1280×800 at device scale factor 1, so every PNG is exactly 1280×800 with no
scaling.

- **Endpoint:** a loopback OpenAI-compatible stub
  ([capture-kit/stub-llm.py](capture-kit/stub-llm.py)) on
  `http://127.0.0.1:8123/v1` answering with pre-generated translations. The
  extension performs the real request, the real SSE stream, and the real
  rendering; only the model behind the endpoint is canned. No real provider,
  endpoint, or API key appears in any screenshot.
- **Pages:** the local demo site in
  [capture-kit/demo-site](capture-kit/demo-site), so no third-party or
  streaming-service UI is shown and nothing is copyrighted beyond our own text.
- **Clip:** the subtitle clip is generated by
  [capture-kit/make-clip.py](capture-kit/make-clip.py); no third-party footage.
- **Language pair:** Auto → Tiếng Việt (the extension's default target language).
- **Subtitles:** Settings → Subtitles → MODE = `Bilingual`, so the overlay shows
  the original cue above the translation.

`02-popup.png` is a composite: the popup is its own window in Chrome and cannot
appear in the same screenshot as the page behind it. The script
([capture-kit/compose.py](capture-kit/compose.py)) pastes the unmodified 340×464
popup capture onto a neutral 1280×800 backdrop. No popup pixel is retouched, and
no UI is invented.
